## 怎么用

- **找东西**：先看上面的导航或 `索引.md`；GitHub 仓库页右上角搜索框支持全文检索。
- **写新笔记**：复制 [`_模板/笔记模板.md`](_模板/笔记模板.md)，放进对应目录，然后在该目录的 `README.md` 和根目录 `索引.md` 各加一行。
- **文件命名**：`主题_关键词.md`，中文，见名知意。一篇只讲一个主题。
- **每篇开头带 frontmatter**（标题、标签、日期、来源），标签用来跨目录聚合。

## 维护约定

1. 做完一件有结论的事 → 结论写进对应笔记 → `git commit && git push`。没推送等于没记。
2. 相对日期一律转成绝对日期（写「2026-08 起」不写「上个月」）。
3. 发现旧笔记错了就直接改或删，不留错的。
4. 分类不够用随时加目录，别硬塞。
