# 深度学习 500 问 · 离线可读版

《深度学习500问》的重排版本，**公式在构建期就渲染成了 HTML**，因此整站不加载任何外部资源、不依赖运行时 JavaScript。断网能读，双击 `index.html` 就能看。

内容来自 [scutan90/DeepLearning-500-questions](https://github.com/scutan90/DeepLearning-500-questions)，原文一字未改，本仓库只做渲染和排版。

## 为什么原版看起来像乱码

不是编码问题——原仓库所有 Markdown 文件都是干净的 UTF-8。真正的原因有两个：

**一是公式没被渲染。** 原站点靠 `unpkg`、`jsdelivr`、`cdnjs` 这三个 CDN 在浏览器里现场加载 MathJax/KaTeX。这些 CDN 在国内经常连不上，脚本一旦加载失败，全书 1900 多条公式就会退化成裸露的 LaTeX 源码：

```
$$\Vert\vec{x}\Vert_1=\sum_{i=1}^N\vert{x_i}\vert$$
```

满屏都是这个，看着就是乱码。本仓库把这一步挪到了构建期，产物里已经是渲染好的 HTML。

**二是原稿里有些公式写法本身有问题**，即使 CDN 正常也渲染不出来。构建脚本会自动修正这几类（本次构建的实际修正数）：

| 问题 | 例子 | 处理 | 次数 |
| --- | --- | --- | --- |
| `$$` 定界符没有独占一行，整段被并成一个段落后按行内规则错误配对，把成片中文吞进数学模式 | `文字\n$$\n公式\n$$\n紧接着的文字` | 拆成独占行并补空行 | 309 |
| 两个行内公式紧挨着，前一个的结束符和后一个的起始符凑成假的 `$$` | `当$x=0$$f'(x)=0.25$` | 中间补一个空格 | 6 |
| 行内公式被换行截断，`$` 的行内规则不跨行 | `使用$\nL(Y, f(x))$来表示` | 合并相邻两行 | 1 |
| KaTeX 不支持 `eqnarray` 环境 | `\begin{eqnarray}` | 转成等价的 `aligned` | 5 |
| 正文被误写进了 `$$` 块内部（块外另有一份正确的重复） | 见 ch07 FID 一节 | 从块尾剥出来当普通段落 | 2 |
| 下标缺花括号，KaTeX 比多数 LaTeX 实现严格 | `_\boldsymbol w` | 补成 `_{\boldsymbol w}` | 1 |

最终 **1926 条公式全部渲染成功，0 失败**。

## 怎么读

- **在线**：仓库启用 GitHub Pages 后直接访问即可。
- **本地**：`git clone` 之后双击 `index.html`。不需要起服务器，也不需要联网——公式字体和样式都在 `assets/` 里。
- **手机 / 平板**：同一份 HTML，窄屏下侧边栏收进左上角的 ☰ 按钮。
- **打印或转 PDF**：浏览器直接打印，样式里已经去掉了导航和目录。

深色模式跟随系统设置。

## 重新构建

Markdown 源文件（`ch*/`）保持原样，HTML 是生成物。改完源文件后重新生成：

```bash
cd tools
npm install
node build.js
```

`tools/build.js` 会重新渲染全部 20 个页面、刷新首页，并把 KaTeX 的样式和字体拷进 `assets/`。构建结束会打印每章的公式数、插图数和失败数——**失败数应当是 0**，不是 0 就说明源文件里有新的公式问题。
